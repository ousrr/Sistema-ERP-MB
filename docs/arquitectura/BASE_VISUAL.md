# Alcance de la base visual

La estructura visual común es:

┌────────────────────────────────────────────────────┐
│ Sidebar │ Header / barra superior                  │
│         ├──────────────────────────────────────────┤
│         │ Navegación interna                       │
│         │                                          │
│         │ Página / contenido                       │
│         │                                          │
└─────────┴──────────────────────────────────────────┘

Los elementos incluidos son solamente presentacionales y reutilizables.
Cada módulo será responsable de sus procesos, datos, API y lógica.
